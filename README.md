# Жас Дарвин

Биология мен ҰБТ-ға дайындыққа арналған интерактивті оқу платформасы (қазақ тілінде).

## Мүмкіндіктері
- **Дашборд:** прогресс, апталық белсенділік, радар диаграмма, ҰБТ динамикасы, белсенділік картасы
- **7 тақырып:** молекулалар, жасуша, генетика, адам, өсімдіктер, эволюция, экология (28 сабақ)
- **ҰБТ дайындық:** 57 сұрақ түсіндірмелерімен, 30 минуттық нұсқа, жылдам жаттығу, қателер дәптері
- **Сурет атласы:** жасушалар, органоидтар, мүшелер, организмдер (анимациялы SVG)
- **ДНҚ зертханасы:** 3D модель, құрастырушы, ҰБТ есептері, генетикалық код және мутация
- **Флэш карталар** (аралықпен қайталау), жоспар күнтізбесі, рейтинг, сөздік

## Іске қосу
Серверсіз статикалық сайт: `index.html` файлын браузерде ашу жеткілікті.
Прогресс браузердің `localStorage` ішінде сақталады.

## Құрылымы
| Файл | Мазмұны |
|---|---|
| `index.html` | Бет қаңқасы, кіру экраны |
| `style.css` | Дизайн, анимациялар |
| `data.js` | Тақырыптар, сабақтар, сұрақтар, сөздік |
| `art.js` | Сурет атласы (SVG) |
| `dna.js` | ДНҚ зертханасы |
| `mol.js` | Биомолекулалар: 3D шар-таяқша модельдері (зертхана, «Күннің молекуласы») |
| `bio.js` | Тінтуірді қуалайтын тірі ағзалар (амеба, туфелька, эвглена, бактерия, эритроцит) |
| `app.js` | Негізгі логика: басты бет, карталар, жоспар, рейтинг, профиль |
| `learn.js` | Дашборд, сабақ, тест қозғалтқышы, атлас, маршрутизатор |
